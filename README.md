# 📄 AI Resume Builder: Interactive Resume Platform

A compact, full-stack resume platform built with the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.

## 🚀 Key Highlights (Resume Focus)
- **Server-Side Pagination**: Efficient pagination (`limit`, `skip`, page count) querying community templates and user resumes from MongoDB.
- **RESTful API Architecture**: Modular CRUD endpoints for resumes and templates with search filtering.
- **AI Bullet & Summary Enhancement**: Google Gemini API integration for automated bullet tailoring and real-time live preview.

## 🛠️ Quickstart (Run with 1 Command)
```bash
npm install
cd backend && npm install
cd ../frontend && npm install
cd ..

# Run full-stack dev servers (Backend :5052, Frontend :5175)
npm run dev
```
